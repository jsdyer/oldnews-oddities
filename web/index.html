Import Library of Congress results

If this browser cannot read a live response, you can still use the tool with official results you save yourself. This does not bypass a Library access restriction.

  1. Open this search as Library JSON. If JSON is displayed, save that page as a .json file. If it shows a verification or error page, the file cannot be imported.
  2. Attach the exact URL of that saved response below. It identifies the search, dates and result page.
  3. Choose the saved JSON file. It is read locally; nothing is uploaded. Imported pages support clippings, source links and exports.

Use the exact address of the response you saved, even if your search form has changed.

Import time is recorded separately. The original retrieval time of an external JSON file is unknown.

Primary pages, curious queries

Each topic is a search recipe, not a list of proven oddities. The bundled shelf preserves the first page of real Library of Congress search results at the displayed collection date. It is a selected discovery sample, not a frequency measure or a complete archive. “Surprise me” chooses among the pages already on your shelf.

More than the OCR

Dates are newspaper publication dates. OCR excerpts, when present, are imperfect machine readings and may miss the matching passage. Open the scan and its text view to check the words, surrounding columns and publication context. This collection covers historical U.S. newspapers; Canadian places may appear in their reporting.

Rights, privacy & expansion

Source: Library of Congress, Chronicling America / National Digital Newspaper Program. The Library believes the collection is in the public domain or has no known copyright restrictions; inspect the record’s rights statement before reuse, particularly for later third-party material. Page images load from the Library. Searches go there only when you submit them; your saved list and imported JSON stay local until you download them.

Every topic, query and default year range comes from config.json. Custom searches work immediately. The repository guide explains how to add as many shelves as you need and refresh them.
